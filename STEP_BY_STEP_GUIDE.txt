🚨 TROUBLESHOOTING:

Problem: "Page not found" at https://stechx.vercel.app
Solution: 
  1. Wait 5 minutes - Vercel might still be building
  2. Go to https://vercel.com/dashboard and check "Deployments"
  3. If it says "Failed", scroll down to see error message

Problem: Backend URL shows error
Solution:
  1. Check Render dashboard at https://dashboard.render.com
  2. Click on stechx-api service
  3. Go to "Logs" tab to see what went wrong
  4. Most likely: build command didn't save - try Step 1 again

Problem: Login not working
Solution:
  1. Check if backend is responding: https://stechx-api.onrender.com/health
  2. Open browser DevTools (F12) and check "Console" tab for errors
  3. Make sure you're using exact credentials:
     alice@company.com / password123
